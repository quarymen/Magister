# Basketball 2D

Новый режим с двумя игроками и двумя кольцами находится в отдельном приложении
`Basketball 1v1.app`; запуск — `start-1v1.command`. Подробности и ограничения
обучения описаны в `README-1v1.md`. Ниже — описание прежнего тренажёра броска.

Нативный 2D-симулятор обучения баскетбольного агента для macOS. Агент в реальном
времени управляет коленями, корпусом, локтем, кистью, силой и моментом выпуска
мяча. Базовая награда за близость равна `max(0, 500 − минимальное расстояние)`.
Точное попадание дополнительно даёт `10 000` очков, поэтому оно значительно
ценнее любого близкого промаха.

Каждая политика проверяется с пяти разных позиций. Нейросеть `5 → 10 → 6`
со 126 обучаемыми весами получает позицию, её квадрат и куб, расстояние до кольца
и обратное расстояние. Она выдаёт параметры коленей, локтя, кисти, силы, момента
выпуска и наклона корпуса. Обучение использует популяцию из 8 вариантов с сохранением
лучшего агента: обычные варианты меняют только часть весов, один исследует дальше,
а один делает особенно маленький уточняющий шаг.

Начальные веса содержат только слабую биомеханическую координацию суставов, а не
готовые броски. При отборе учитывается средняя награда и отдельно худшая позиция.
Каждые 12 поколений один кандидат получает усиленную мутацию, чтобы агент мог выйти
из локального максимума, если застрял на трёх или четырёх попаданиях из пяти.

## Запуск

```bash
open "Basketball 2D.app"
```

## Управление обучением

- `T` — пауза или продолжение обучения
- `S` — скорость симуляции: 1x, 4x или 12x
- `R` — сбросить опыт и начать со слабого агента

Кнопки паузы и сброса также доступны мышкой. График показывает награду за
последние попытки, а панель слева — действия текущей политики агента.

Исходный код симулятора: agent.m. Файлы main.m и app.py сохранены как предыдущие версии.

Пересборка:

```bash
clang -fobjc-arc -fno-modules agent.m -framework Cocoa -o "Basketball 2D.app/Contents/MacOS/BasketballNative"
```
